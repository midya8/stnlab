# Exact existential projection

A hidden time point still has to exist. This inspector projects a tiny simple temporal network onto selected retained points. It preserves the original network's implied constraints, rather than simply deleting edges that touch hidden points. It also tests one complete retained assignment and returns a full extension or a path proving rejection.

## Input and semantics

Input has exactly `base`, `keep` and `values`. Base uses the original STNLab contract: 1..6 points, at most 12 integer `[u,v,w]` edges, weights -20..20, meaning `t[v]-t[u] <= w`. Keep is a sorted unique subset of original point IDs, includes 0, and is never renumbered. Values align with keep, are integers -100..100, and set t0=0. Bounds and generated witnesses are internal mathematical values and are not clipped to those public input windows.

Times range over the reals and can be negative. The common anchor removes translation, not a nonnegativity assumption. The integer input/query windows are interface limits, not integer-time semantics. Projection means the set of retained assignments for which **some simultaneous values for all hidden points** satisfy every original edge. An inconsistent original network has an empty projection, even when the retained induced graph is feasible.

For a consistent base with shortest-path closure D and retained set K, the exact projection is the restriction D[K,K]. Its finite off-diagonal entries are a complete difference-constraint representation on the original retained IDs. It need not be a minimal-cardinality edge set; up to 30 internal projected edges are allowed. These generated edges can exceed the public input edge-count/weight limits and are not claimed directly round-trippable as a base input.

The native generator computes Floyd-Warshall closure and Bellman-Ford potentials from an implicit zero-weight super-source. Every projected finite pair has an original-index canonical shortest simple path and a full original-network schedule attaining that difference, obtained by adding its reverse equality bound. Missing paths have a full anchored ray and common base schedule. Each finite endpoint is individually attainable, not necessarily jointly selectable with other endpoints.

## Query and lift

A retained assignment is accepted exactly when it satisfies all finite projected bounds. The generator pins every retained value with edges `0 -> i` of weight value[i] and `i -> 0` of weight -value[i], then computes a complete original-network potential. The returned schedule fixes all retained values together and satisfies every original edge.

On rejection, the first violated finite bound in retained row-major order supplies an original path u -> v. Its weight is D[u,v]. The fixed-value edges v -> 0 and 0 -> u close a walk of weight `D[u,v]-value[v]+value[u] < 0`. The report contains the original path and exact negative sum. This obstruction may repeat a point or use a zero-weight anchor self-loop; it is not a globally canonical simple negative cycle. For an inconsistent base, the original analyzer's canonical negative cycle is returned instead, and no matrix, projected edge set, pair report or query lift is reported.

## Why naive deletion can fail

The comparison keeps only original edges with two retained endpoints and closes that induced graph. For every finite projected bound strictly stronger than its induced counterpart, the inspector returns a separate retained counterexample. It is constructed by adding the reversed violated bound at least one unit beyond the exact limit to the induced graph. It satisfies every retained original edge but cannot extend through all hidden points. Counterexamples can lie outside the public assignment window and are not the queried assignment. If the two closed matrices agree for a consistent base, their retained solution sets agree, not merely the selected query's outcome.

Default: `t1-t0 <= 4`, `t2-t1 <= 3`, `t2-t0 <= 12`; keep `[0,2]`. The hidden path implies `t2-t0 <= 7`. Query `[0,7]` extends to `[0,4,7]`. Query `[0,8]` obeys the retained direct edge but has no full extension. A four-point control also shows why individual time intervals do not suffice to test a joint retained assignment.

## Verification and reproduction

`python -m stnlab.projection input.json --output report.json` generates an atomic report. `python -m stnlab.projection report.json --verify` checks it. Installed console entry point: `stnlab-projection`. Schema: `stnlab-projection-v1`. Strict original JSON handling rejects duplicate keys, nonfinite values and unknown fields; report replay is type-exact.

The verifier never calls the generator, its shared builder, Floyd-Warshall, native potentials or native canonical paths. It uses the original independent permutation/edge-product oracle to reconstruct closure, canonical paths, full schedules and cycles. It independently checks query feasibility by detecting negative cycles after adding every pin, rather than assuming the projected bounds are sufficient. It recomputes complete reports, not a scalable local proof checker.

Seven new native tests cover all 256 two-point networks with four edge states per ordered pair, both retained sets and sampled assignments; all 64 three-point acyclic networks with four retained sets and sampled assignments; 70 seeded networks; 120 edge permutations; strict report forgeries, validation and CLI atomic behavior. A separate Fourier-Motzkin elimination audit eliminates hidden points before closing and checks its result against projected closure. Full schedules, path sums, ray slopes and every naive counterexample are directly checked. Browser JavaScript uses independent recursive simple-path/cycle search. Two cross-engine/validation tests and an actual-Chrome test check all 12 controls at 320, 390 and 1280 pixels, all selected pairs/losses/lifts, matrices, slacks, exports and stale clearing. Existing native and browser tests remain unchanged. Installed-wheel reproduction covers all three families outside checkout.

## Source ledger

1. Antoine Mine, *A New Numerical Abstract Domain Based on Difference-Bound Matrices*, PADO II, 2001. https://perso.lip6.fr/Antoine.Mine/publi/article-mine-padoII.pdf . Primary research. Read Theorem 2 (closure and saturation), Theorem 4 (single-variable interval projection), and the Forget operator/Theorem 10 (existential elimination). The paper uses projection for the one-variable interval operation and forget for existential elimination with extrusion. This inspector explicitly uses multi-variable existential projection, not reset-to-a-fixed-value semantics. No widening, abstract interpreter or new abstract domain is implemented.
2. H. H. Bui, M. Tyson and N. Yorke-Smith, *Efficient Message Passing and Propagation of Simple Temporal Constraints: Results on Semi-Structured Networks*, 2008. https://starlab.ewi.tudelft.nl/papers/n59.pdf . Primary research. Background and Terminology explicitly states that STNs are binary decomposable and the minimal network of a projection is the original minimal network restricted to the retained variables. Variable Elimination for STNs gives the message-STN representation. This inspector does not implement Prop-STP, cluster-tree elimination, triangulation or its performance claims.
3. Dechter, Meiri and Pearl, *Temporal Constraint Networks*, Artificial Intelligence 49, 1991. https://ftp.cs.ucla.edu/pub/stat_ser/r113-reprint.pdf . Primary foundational research. Original PDF Section 3 supplies the shortest-path/minimal-network and decomposability results. Browser extraction omits some governing Section 3 text; original PDF text is the authority for it. Appendix extension discussion is consistent with the explicit full-lift construction here.
4. Archive of Formal Proofs, *Difference Bound Matrices*, `DBM_Constraint_Systems`. https://isa-afp.org/browser_info/current/AFP/Difference_Bound_Matrices/DBM_Constraint_Systems.html . Formal reference for difference constraints, solution semantics and closure equivalence. Context only, not a proof of this code; its strict-bound/timed-automata operations are outside this inspector's scope.
5. Piotr Indyk, MIT 6.006 Lecture 17, *Solving a system of difference constraints*, 2011. https://courses.csail.mit.edu/6.006/spring11/lectures/lec17.pdf . University lecture. Difference-constraint graph, negative-cycle contradiction and super-source potential construction. Full schedule pinning is an application of those constraints, not a new algorithm.
6. NetworkX official `negative_edge_cycle` documentation. https://networkx.org/documentation/stable/reference/algorithms/generated/networkx.algorithms.shortest_paths.weighted.negative_edge_cycle.html . Official implementation documentation. Whole-graph negative-cycle scope across disconnected components. Not a dependency or claim that NetworkX independently verified these reports.

All six sources were fetched and governing sections inspected. Original controls, interface, code and tests are written for this project.
